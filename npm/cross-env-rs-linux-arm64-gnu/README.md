# cross-env-rs platform binary (placeholder)

This package will ship a platform-native Rust binary for [`cross-env-rs`](https://www.npmjs.com/package/cross-env-rs) — a drop-in replacement for [`cross-env`](https://github.com/kentcdodds/cross-env).

## Status: placeholder

The package name is reserved. The real binary ships with version `0.1.0`.

You don't install this directly — it is pulled in automatically as an `optionalDependency` of the main `cross-env-rs` package on the matching platform.

- Repo & roadmap: <https://github.com/Segodnya/cross-env-rs>
- Main package: <https://www.npmjs.com/package/cross-env-rs>
